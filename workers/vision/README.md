# workers/vision

Python 3.11 reconstruction workers (docs/03 §4, docs/05). Built in **Milestone M4**;
this directory is scaffolded early so the monorepo layout (docs/03 §2) is stable.

Planned workers: `lidar-parse`, `detect-segment`, `depth-scale`, `match-texture`,
`scene-assemble`, consuming BullMQ jobs from Valkey and validating payloads against
the JSON Schemas generated by `packages/schema`.

Licensing: Python runtime dependencies must satisfy the docs/08 §7 allowlist;
`pip-licenses` runs in CI once this package has dependencies.
